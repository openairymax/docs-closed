## Round 6-10: 核心修复阶段

### Round 6: memoryrovol桩函数清除

**核心任务**: 清除memoryrovol模块的所有桩函数

**发现的桩函数**:

#### STUB-01: curl_stub.h (25个假libcurl API)

```c
/* curl_stub.h - 完整的假libcurl API */
typedef void CURL;
typedef int CURLcode;

static inline CURL* curl_easy_init(void) { return NULL; }
static inline CURLcode curl_easy_perform(CURL *curl) { return CURLE_FAILED_INIT; }
// ... 25个假函数
```

**影响链路**:
```
llm_client.c → #ifdef AGENTOS_HAS_CURL → else → #include "curl_stub.h" → 返回假SUCCESS
```

#### STUB-02: sqlite3_stub.h (30+个假SQLite3 API)

```c
static inline int sqlite_open(const char *filename, sqlite3 **ppDb) {
    return SQLITE_NOMEM;  // 永远内存不足
}
```

**影响**: 向量存储功能完全不可用

#### STUB-03: ml_planner.c PHASE2-IMPLEMENTED

```c
data->model = NULL;              // 永远空
data->fallback_mode = true;       // 永远fallback
return AGENTOS_SUCCESS;           // 假成功
```

#### STUB-04: llm_client.c Degraded Mode (12处)

```c
if (!curl) {  // 总是true（来自stub）
    service->initialized = 1;     // 假装成功
    *out_service = service;       // 返回service
    return AGENTOS_SUCCESS;       // 但LLM不可用！
}
```

## 关键决策记录

### 决策1: 概率乘法 vs 加法（准确率计算）

**背景**: 设计文档声称99%任务完成准确率

**原始计算（错误）**:
```
70% + 15% + 10% + 10% + 8% + 5% = 118% > 99%
```

**正确计算**:
```
准确率 = 1 - (1-0.70) × (1-0.15) × (1-0.10) × (1-0.10) × (1-0.08) × (1-0.05) = 83%
```

**决策**: 将目标调整为85-90%（考虑优化空间）

### 决策2: Phase 2流式批判的三方案选择

## 双思考系统设计演进

### 理论基础

**Kahneman的双系统理论**:
- **System 1 (S1)**: 快速、直觉、自动化（对应7B参数本地模型）
- **System 2 (S2)**: 缓慢、理性、深思熟虑（对应70B+参数云端模型）

### 五阶段流程设计

**来自[双思考系统全方位设计01](../../../.vscode/双思考系统全方位设计01.md)**:

```
Phase 0: 指令拆解 (S1主导)
├── 意图解析
├── 任务分解
└── 上下文检索(MemoryRovol L2)

Phase 1: 规划 (S2主导 + S1预验证)
├── 策略选择
├── 资源分配
├── DAG计划生成
└── S1快速验证可行性

Phase 2: 流式批判执行 (S1+S2协作) ← 核心缺失
├── S2每15 token生成
├── S1实时验证合理性
├── 不合理则S2局部修正
├── 专业S1交叉验证
├── 修正失败3次 → 记录+人工介入
└── 每10步注入相似上下文(MemoryRovol)

Phase 3: 审计委员会 (S1+S2+专家S1)
├── 子任务完成后触发
├── S2总结结果
├── S1+专业S1独立验证
├── 结论一致 → 通过
├── 结论不一致 → 辩论(最多2轮) → 仲裁
└── 记录到MemoryRovol L1/L2

Phase 4: 目标对齐 (定期检查)
├── S2每小时生成进度摘要
├── 写入MemoryRovol L2
├── 与原始目标计算语义相似度
├── 相似度<0.7 → 触发重新规划
└── 记录漂移事件到L1
```

### 流式批判Python伪代码（来自设计文档）

```python
def streaming_critique(prompt, s2, s1, s1_expert, memory):
    full_output = []
    buffer = []
    token_count = 0
    step = 0

    for token in s2.stream(prompt):
        buffer.append(token)
        token_count += 1
        full_output.append(token)

        if token_count % 15 == 0 or token in ['.', '!', '?', '\n', ';']:
            chunk = ''.join(buffer)
            is_ok, critique = s1.check(chunk, context=prompt, history=full_output)
            if not is_ok:
                correction_attempts = 0
                while correction_attempts < 3:
                    corrected = s2.correct(chunk, critique, context=prompt)
                    if s1_expert.verify(corrected, chunk, critique):
                        buffer = [corrected]
                        full_output[-len(chunk):] = list(corrected)
                        break
                    correction_attempts += 1
                else:
                    memory.store_error(chunk, critique)
                    raise TaskError("Unresolvable error in reasoning")
            yield ''.join(buffer)
            buffer = []
            token_count = 0
            step += 1

            if step % 10 == 0:
                similar_context = memory.retrieve_similar(''.join(full_output[-300:]))
                if similar_context:
                    s2.inject_context(similar_context)
```

## MemoryRovol记忆卷载实现路径

### 理论基础

**来自[emoryRovol独立突破上下文窗口限制的可行性](../../../.vscode/emoryRovol独立突破上下文窗口限制的可行性.md)**:

**核心类比**: 虚拟内存系统

```

│ L3 Structure Layer (结构层)                │

│ - 图结构(Graph)存储关系                      │
│ - 实现度: 70%                               │

│ - 混合检索(Hybrid Search)                  │

│ - 元数据+压缩                               │
│ - 实现度: 95%                               │
└─────────────────────────────────────────────┘
```

### 分时推理机制（核心创新）

**设计要求**:
```
分时推理 + 记忆交换流程:
  1. 任务切片: 1000小时 → 大量子任务
  2. 每次只处理一个子任务:
     a. 加载上下文 + 检索相关历史(L2语义检索)
     b. 执行子任务(S1/S2协作)
     c. 关键结果写入MemoryRovol L1
  3. 下一个子任务:
     a. 检索上一子任务摘要(L2)
     b. 检索相关规则(L4)
     c. 目标对齐检查(Phase 4)
  4. 循环直到任务完成
```
