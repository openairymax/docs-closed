## 🎯 替换策略

### 1. `strcpy` → `strncpy` 或 `agentos_safe_strcpy`
```c
// 不安全
strcpy(dest, src);

// 安全选项1: strncpy
strncpy(dest, src, dest_size - 1);
dest[dest_size - 1] = '\0';

// 安全选项2: agentos_safe_strcpy
agentos_safe_strcpy(dest, dest_size, src);
```

### 2. `strcat` → `strncat` 或 `agentos_safe_strcat`
```c
// 不安全
strcat(dest, src);

// 安全选项1: strncat
strncat(dest, src, dest_size - strlen(dest) - 1);

// 安全选项2: agentos_safe_strcat
agentos_safe_strcat(dest, dest_size, src);
```

### 3. `sprintf` → `snprintf`
```c
// 不安全
sprintf(buffer, format, ...);

// 安全选项: snprintf
snprintf(buffer, buffer_size, format, ...);
```
