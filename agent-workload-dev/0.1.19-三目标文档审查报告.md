## 2. P0 — 阻断级（2 项）

### P0-1 §6.6(甲) 与 (乙) 减重账**同名同值混算**（−161,925）

**问题**：§6.6(甲)（现行机制核口径）在「减重手段」行直接写入与 (乙)（旧八模块口径）**完全相同的四个分量**，并冠以「机制核内实际净减」。

**证据**：

| 位置 | 内容 |
|------|------|
| [① L1797-1800](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L1797-L1800) | （甲）机制核基线 **133,881**；「减重手段（**机制核内实际净减**）｜ K 塌缩 −106,925 / D 归位消解 −30,000 / S 样板生成 −20,000 / A 清扫 −5,000」 |
| [① L1815](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L1815) | （乙）「减重（K −106,925 / D −30,000 / S −20,000 / A −5,000）｜ **−161,925**」 |

**三重反证**：

1. **算术自毁**：若该组数确为「机制核内净减」，则 `133,881 − 161,925 < 0`——机制核行数为负，门禁无从执行。
2. **通道作用域矛盾**：S 通道明确作用于**形态面** `daemons` 的 `main.c`（[① L1107](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L1107)）；D 通道含 `daemons/common` 双向消解（[① L1569](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L1569)），而 `daemons` **不在机制核五单元内**（[① L172-176](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L172-L176)）；K 通道含「4 类随迁出不计」（[① L1570](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L1570)）。故该组数**必然跨口径**。
3. **同值双口径**：同一组四个数字在 (甲)(乙) 两处出现、且 (乙) 明标为「八模块口径」，属**未改写的复制残留**。

**连带**：[① L284](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L284) 又称「缺口 33,881 主要由 §1.4 减重通道（K −106,925 / D −30,000 / S −20,000 / A −5,000）**在机制核内的实际净减**补足」——与 [① L1801](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L1801)「兜底（机制核内，唯一可抵扣）仅 `heapstore` −2,000」并置时，同一节内出现两种「机制核内可抵扣量」，自相矛盾。

**建议**：

- (甲)「减重手段」行改为：**「减重通道总量（八模块口径）：−161,925；其中机制核内可抵扣分量以逐轮实测公示为准（K′/D′/S′/A′，当前未定值）」**；或直接删除该行，仅保留「兜底（机制核内，唯一可抵扣）`heapstore` −2,000」，避免以跨口径数值充当机制核减重。
- [① L284](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L284) 同步改为「由 §1.4 减重通道**在机制核内的实测分量**补足」，与 (甲) 表口径对齐。
- [① L1801](file:///home/spharx/spharxworks/airymaxhub/docs/docs-closed/agent-workload-dev/0.1.19-架构改进方案.md#L1801) 兜底行已正确区分形态面项（`daemons/common`、`protocols/core`「不抵扣」），保留即可。
