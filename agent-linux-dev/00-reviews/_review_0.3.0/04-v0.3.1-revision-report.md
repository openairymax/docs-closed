3. 不属于 v0.3.0 审查报告 36 项问题范围

**1.0.1 建议**：AirymaxRT 侧可补充 typedef 使用规则明文（何时用 typedef、何时用 `struct foo`），作为 P2-10「AirymaxRT 术语一致性复查」的扩展项。
