## 3. L1 组装证据

- 组装容器内产出 `airymaxos-0.0.3-x86_64.iso` 与同名 `.sha256`，`iso-manifest.txt` 记录卷标、引导项与载荷摘要。
- 卷标 `AIRYMAXOS`，BIOS 引导 `-b /isolinux/isolinux.bin`，UEFI 引导 `-e /images/efiboot.img`，GPT + isohybrid MBR 同时可用。
- 内核来源与发行资产同源：产品轮用 `ci/ci.sh release-rpms` 取 Release `v0.0.3` 的 4 架构内核包并逐件校验 `.sha256sum`，ISO 内不再二次编译，避免同名包哈希分叉。

## 5. 交付通道

- ISO 3.43 GiB 超出 GitHub Release 单资产 2 GiB 与 AtomGit 网关 3 GiB 上限，改走 OCI 制品通道：
  `ghcr.io/openairymax/airymaxos-iso:v0.0.3`，layer digest 即 ISO 的 sha256。
- 发布挂在 accept 之后且排除验收剖面：只有双固件装机与冷启动通过的字节才占用发行 tag。
- 幂等：同 tag 已存在时先比对远端 layer 摘要，相同视为已发布不重传，不同即失败（确需覆盖才 `--force`）。
- `iso-oci.txt` 记录 `ref/tag/sha256/size/layer/pull` 六项，消费者 `oras pull` 后可用
  `sha256sum -c` 与 layer digest 双向对账。
