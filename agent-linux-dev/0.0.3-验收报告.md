## 8. 缺陷分析

### 8.1 BIOS 腿串口静默（已修复）

2026-10-30 的流水线轮次暴露一处验收链缺陷，不是产品缺陷，但会让验收结论
失真，必须记录在案。

**现象**：run `41121955316`（`88f50b0`）的 `Install and cold boot (BIOS +
UEFI, CD-ROM)` 步骤跑了 68.75 分钟后失败。逐腿拆开看，`run-bios-1` 的
TAP 心跳从 +30s 到 +3570s 共 120 次全部为空，`install.log` 0 字节；
同批次 `run-uefi-1` 8 分钟装完并冷启动 14 秒。同一份 ISO、同一台宿主，
两条固件腿的结果不可能差到这个程度，说明差异在引导链而不在载荷。

**根因（两处，同一来源）**：`isolinux.cfg` 的缺省引导项没有 `console=ttyS0`。
BIOS 腿把全部安装输出留在 VGA，串口一无所有，验收侧只能看到「空心跳」；
同时该缺省项挂在介质自检（media check）上，BIOS 装机先做整盘校验，等于在
装机前多跑一遍 3.4 GiB 读盘。UEFI 腿走 `grub.cfg`，两项都不受影响——这解释
了为什么只有 BIOS 腿失败。

**为什么没有被更早发现**：`install-test.sh` 的心跳只打印串口最后一行非空
内容，尾行为空时打印空行。于是「安装器在跑」与「安装器一个字都没写串口」
在日志里长得完全一样，读日志的人只能等到 3600 秒超时，再由 `fail_note`
归因。卡点无法定位，正是这一类观测缺口造成的。

**修复**：
- distro `e75f12d`（父仓库 `0b48f81`）：BIOS 缺省项离开 media check，并补
  `console=ttyS0,115200`，与 UEFI 腿的串口契约对齐。
- distro `a3feddf`（父仓库 `9f13934`）：心跳在尾行为空时打印日志字节数，
  0 B 即「该腿从未写过串口」，把静默从「看起来像在启动」变成可读事实。
- 父仓库 `22163f5`：验收腿按固件拆成三个独立步骤（USB / BIOS CD-ROM /
  UEFI CD-ROM），任一条腿的失败不再需要从合并日志里反推是哪条固件出的问题。

**教训**：验收脚本的可观测性本身就是交付物的一部分。判负条件写得再准，若
现场输出无法区分「慢」与「静默」，排障仍然只能靠猜；桥接这一点的成本只是
一次 `stat`，收益是下一次故障能在一分钟内定位。

### 8.2 模块未签名（已修复，待下一轮 ISO 复核）

**现象**：B50 装机后 `/proc/sys/kernel/tainted` = 8192（TAINT_UNSIGNED_MODULE）。
`readelf -S` 看包内模块，节表只有 `.modinfo` 与 `.BTF`，没有 `.module_sig`；
`modinfo -F sig_id` 为空。

**排查**：已排除 brp-strip。本机用 `strip -g` 与 `strip --strip-unneeded`
对带签名的模块实测，`.module_sig` 均保留；且 `scripts/Makefile.modinst`
的顺序是 install → strip → sign，签名在 strip 之后追加，正常路径不会被
后续去符号抹掉。根因是 `modules_install` 的签名环节在打包机上没有生效。

**影响**：签名是装机后判断「模块是否本发行版产出」的唯一凭据。当前它只
表现为 taint 记账；一旦按安全基线打开 `CONFIG_MODULE_SIG_FORCE`，全部
模块会被内核拒载，系统直接失去网卡与文件系统驱动。

**修复**：
- distro `d6d40c6`（父仓库 `66a1669`）：`%install` 在 `modules_install`
  之后抽样一个 `.ko`，缺 `.module_sig` 时对已安装模块就地执行
  `modules_sign`；`%check` 增加全量扫描，任一模块缺签名即中断打包。
- distro `595db52`：冒烟 T6 增加两条断言——模块文件里必须有
  `.module_sig`，`/proc/sys/kernel/tainted` 的 8192 位必须为 0。
- 回归：`tools/tests/test_run_smoke.py` 增加未签名模块与 taint=8192 两个
  用例，72 项全过。

**状态**：代码侧已收口，需下一轮流水线产出 ISO 后在 B50 复核 taint=0，
此前本报告中的实机结论按「taint=8192 已知」记录。
