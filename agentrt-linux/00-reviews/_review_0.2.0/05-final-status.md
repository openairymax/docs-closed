## 3. 关键技术约束最终确认

### 3.1 微核心 vs 微内核

| 组件 | 定位 | 术语 |
|------|------|------|
| agentrt | 用户态运行时 | **微核心**（micro-core），基于 seL4 微内核思想抽象 |
| agent-linux | OS 发行版 | **微内核**（micro-kernel），真正的操作系统内核 |

**验证**：全仓"微内核原语"5 处均为合法禁词清单引用，无概念混淆 ✅

### 3.2 IRON-9 v2 三层共享模型

| 层级 | 定义 | 代码共享 |
|------|------|---------|
| [SC] 共享契约层 | 6 个头文件完全共享 | `include/airymax/` 下 6 个头文件 |
| [SS] 语义同源层 | API 签名相同，实现独立 | 命名约定、错误码体系、注释风格 |
| [IND] 完全独立层 | 完全独立实现 | 各自专属代码 |

**6 个 [SC] 头文件**：
1. `bpf_struct_ops.h` — sched_ext BPF 调度器
2. `memory_types.h` — MemoryRovol L1-L4
3. `security_types.h` — Cupolas capability + LSM
4. `cognition_types.h` — CoreLoopThree + Thinkdual
5. `sched.h` — SCHED_EXT + 任务描述符 + vtime
6. `ipc.h` — IPC magic + 128B 消息头

**验证**：全仓 6 个头文件引用一致，0 处"4 个"残留（1 处合法历史叙述） ✅

### 3.3 关键 magic 值

| magic 值 | 含义 | 用途 |
|---------|------|------|
| 0x41524531（'ARE1'） | IPC magic | IPC 消息头标识 |
| 0x41475453（'AGTS'） | 任务描述符 magic | 任务描述符标识 |

**验证**：IPC magic 78 处 13 文件一致；任务描述符 magic 172 处 30 文件一致 ✅

### 3.4 SCHED_EXT=7 约束

| 约束 | 状态 |
|------|------|
| 禁止 `#define SCHED_AGENT <数字>` 宏 | ✅ 0 残留 |
| SCHED_AGENT 仅作为 sched_ext BPF 策略名称 | ✅ `SCHED_AGENT_NAME "sched_agent"` |
| 复用内核 SCHED_EXT=7 | ✅ 已声明 |

### 3.5 定点数约束

| 约束 | 状态 |
|------|------|
| 内核态 [SC] 头文件禁用 float | ✅ 0 残留 |
| 使用 Q16.16 定点数 | ✅ `airymax_q16_t = int32_t` |
