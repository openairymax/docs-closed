### 最严重发现

**P0-R01**：EV-02 声称 OLK-6.6 顶层有"28 个目录"，**实际只有 24 个**。此错误贯穿文档 11 处（EV-02 + §1.1 + §3.2 + §3.3 + §11.2 + 附录 A 等），是 v0.2.4 引入的**事实性错误**——v0.2.4 修正 v0.2.2 的"21 个"时矫枉过正，误写为"28"。

**P0-R02**：§3.2 kernel/ 目录结构**遗漏 4 个上游顶层目录**——`kernel/`（上游内核核心，含 sched/locking/irq/futex/bpf/cgroup/module/trace/rcu 等 22 子系统）、`tools/`（40+ 子目录）、`LICENSES/`、`rust/`。其中 `kernel/`（上游）被 `corekern/`（Airymax 新增）隐性替代但关系未声明，**动摇模型 A "完整 fork" 的根基**。
