## 摘要

DeepSeek 以约 200 人规模、受限算力（萤火集群 PCIe A100 无 NVLink）在三年内完成 V2→V3→R1→V3.2→V4 五次迭代，成本仅为同类 1/10 量级。其工程思想的核心不是单一技术突破，而是一整套**「把资源约束写进目标函数」的方法论**：架构为推理成本设计、通信与计算重叠、约束用软调节而非惩罚、机制级消融 + 数据全公开。

对 agentrt 的借鉴意义在于：agentrt 与 DeepSeek 共享「调度即核心价值」「计算-存储分离」「可复现性」等哲学，其 HAI-LLM 任务级分时调度、3FS 存储分层、无辅助损失软约束、可抢占 rollout 服务等思想可直接映射到 sched_d / 四层记忆 / 任务大厅 / 双思考机制。

## 一、系统架构哲学

### 1.1 稀疏哲学：总容量与激活成本解耦

三代旗舰（V3 671B/37B、V3.2 685B、V4 1.6T/49B）一脉相承的权衡：**总参数决定能力上限，激活参数决定单次成本，路由负责动态取舍**。V4-Flash 以 13B 激活参数成为行业"智效比斩杀线"。

> 借鉴：17 个 daemon 不必全量常驻。按任务蓝图只激活所需 daemon 子集（纯文档任务不拉起视觉链），把「平台容量」与「单任务开销」解耦；为高频 daemon 设冗余副本。

### 1.2 无辅助损失负载均衡：软调节而非惩罚

MoE 负载不均衡的经典解法是辅助损失，但会污染主任务梯度。DeepSeek-V3 改为给每个路由专家加**可学习偏置 bias**，训练步末按实时负载动态调整（γ=0.001 衰减），配极小权重（α=0.0001）的序列级平衡损失兜底，HumanEval 相对提升 21%。

> 核心思想：**当"约束手段"本身伤害主目标时，把约束从损失函数里拿出来，放进调度/路由机制做软调节。**
>
> 借鉴：sched_d 对 17 个 daemon 的负载均衡不用"惩罚性限流"（对慢 daemon 扣分），改为**可调偏置的软路由**——每个 daemon 带权重 bias，按实时负载/延迟动态微调，避免伤害任务主目标（完成率/质量）。

### 1.3 MLA：为推理成本设计架构，而非先架构后优化

MLA 把 K/V 低秩压缩进共享潜向量，KV 缓存压缩约 93%。关键工程点：**架构选择的首要约束是推理期内存/带宽成本**（长上下文下 KV cache 是真正瓶颈），而非训练期准确率。V4 演进为 CSA+HCA 混合稀疏注意力（先压缩再 top-k 精读），1M 上下文下推理 FLOPs 仅为 V3.2 的 27%、KV 缓存为 10%。

> 借鉴：与 agentrt「为运行时成本设计机制」同构——记忆系统的设计约束是运行时内存/带宽/延迟，而非存储完备性。记忆召回采用**两级检索**（廉价索引粗筛 → top-k 精读），与 CSA/DSA 先索引后精读同构。

### 1.4 稳定性优先：一切创新以「可复现、不炸」为前提

V3 全程 14.8T token 预训练无一次不可恢复 loss spike、无一次回滚；V4 用 mHC（流形约束超连接，残差矩阵约束到双随机矩阵流形、谱范数 ≤1）+ Muon 优化器从数学上保证深层堆叠稳定。

> 借鉴：agentrt 的任何机制创新（调度策略、记忆压缩、双思考路由）都应有机制级稳定性证明或回归门禁；batch-invariant 确定性内核（同输入必同输出）是「Agent 行为可审计/可回放」的前提。

## 二、训练/推理基础设施

### 2.1 HAI-LLM：轻量框架 + 任务级分时调度

自研轻量训练框架，四种并行按需组合（V3 用 16 路 PP + 64 路 EP + ZeRO-1 DP，刻意不用昂贵的张量并行）。萤火集群以**「任务级分时共享」**调度：秒级响应、集群占用率 96%、闲时算力对外共享（全年 27% GPU 时用于科研支持）。

> 借鉴：与 agentrt sched_d/任务大厅定位高度同构。任务大厅借鉴「分时共享 + 闲时算力复用」：低优先级后台任务（记忆整理/模式挖掘）填满空闲 daemon 时段，提升平台整体利用率。

### 2.2 DualPipe 与计算-通信重叠：把「等」变成「算」

MoE 跨节点通信使计算:通信 ≈ 1:1。DualPipe 用双向流水线消除气泡，把每个 chunk 拆成 attention/dispatch/MLP/combine 四段精细调度，让通信"藏"在计算背后。

> 核心思想：**优化瓶颈不是提升瓶颈本身的吞吐，而是让瓶颈时间与其他资源的时间重叠。**
>
> 借鉴：双思考机制——think_d 深度思考流与 gateway 的 I/O/工具调用流并行重叠，思考过程不阻塞网络往返；GCCP 按「思考-通信交错」调度而非串行 wait。DeepEP「通信不占任何 SM 资源」思想 → 工具调用/网络 I/O 不应阻塞思考线程。

### 2.3 按场景分设实现 + 资源占用可控（DeepEP/FlashMLA/DeepGEMM）

- DeepEP 按场景（prefill 高吞吐 / decode 低延迟）提供两套内核；基于 hook 的通信-计算重叠，通信零 SM 占用。
- FlashMLA：分页 KV cache + 按序列长度动态切换「计算优先/内存优先」模式，带宽利用率近 90%。
- DeepGEMM：FP8 GEMM 核心仅约 300 行 CUDA，JIT 运行时编译，性能超过千万行级工程库。

> 核心思想：**同一个能力（通信）要为不同场景（吞吐 vs 延迟）提供不同实现；少而精的专用内核 > 大而全的通用框架。**
>
> 借鉴：双思考按任务预算动态切换——简单任务走「快思考（直觉直出）」，长程任务走「慢思考（反思+自验证）」，对应 V4 三档 Think（非思考/High/Max）；蓝图调度为每个任务显式分配「思考预算」。

### 2.4 3FS + smallpond：计算-存储分离、强一致、POSIX 兼容

3FS：SSD+RDMA 解耦存储池（180 节点 6.6 TiB/s）、CRAQ 链式复制强一致、无状态元数据服务（FoundationDB 事务 KV）、FUSE/Native 双客户端、KV cache 外置 SSD。smallpond 基于 DuckDB+3FS，无常驻服务、按需拉起。

> 核心思想：**基础设施「解耦 + 线性扩展 + 强一致 + 熟悉接口（POSIX）」，应用无需感知数据位置。**
>
> 借鉴：四层记忆系统照此分层——L1 原始卷=原始数据存储（不感知位置、线性扩展），L2 特征=无状态数据处理管道，L3 结构=事务 KV（元数据/索引强一致），L4 模式=热缓存；记忆写入提供强一致语义，避免「写后读不到」；高频 L4 驻留内存，低频 L1 落盘可寻址（KV cache 外置 SSD 的冷热分层同构）。

### 2.5 开源的「可组合底座」策略

2025 开源周连续 5 天开源 FlashMLA / DeepEP / DeepGEMM / DualPipe+EPLB / 3FS+smallpond，均为**真实生产代码、小而独立、MIT 协议**，通过 open-infra-index 汇总为「可单独选用、可学习」的模块栈，而非一个巨型框架。公开 profile 数据以增强可复现性。

> 借鉴：agentrt 17 个 daemon 独立可复用、每个机制内置 A/B 开关与基准；以「生产级小组件 + 公开基准数据」建立生态信任，而非演示级大框架。

## 三、强化学习与推理引擎

### 3.1 R1 的 RL pipeline：能力靠纯 RL 涌现，可用性靠 SFT 塑形

- R1-Zero：纯 RL（GRPO + 规则奖励）即涌现自我验证、"aha moment"等行为——**可验证奖励驱动的纯 RL 足以激发复杂推理**。
- R1：针对可读性差问题做工程化收敛：冷启动 SFT（数千条长 CoT）→ 推理导向 RL（+语言一致性奖励）→ 拒绝采样生成 60 万推理 + 20 万非推理数据再 SFT → 全场景 RL。
- 蒸馏：把 R1 推理蒸馏到 1.5B–70B 小模型，效果优于直接 RL——**复用已验证的能力，而非重复造轮子**。

> 借鉴：Agent 能力演进也分阶段：先冷启动（少量高质量轨迹示范）再强化，避免纯 RL 产出「能力强但不可用」的行为；把拒绝采样出的好轨迹沉淀为模板库（对应 L4 模式记忆）。

### 3.2 GRPO：省掉 critic，用组内相对比较代替绝对值评估

对同一问题采样 G 个输出，用组内均值/标准差归一化得 advantage，KL 正则直接进损失。RL 训练成本降低一个量级。

> 核心思想：**当一个昂贵组件只用于「相对比较」时，可以用廉价的组内采样统计替代。**
>
> 借鉴：agentrt 对 Agent 行为做 RLVR 时，用「同任务多 Agent 采样结果组内归一化」做优势估计，无需昂贵的评审 daemon 全程打绝对分。

### 3.3 奖励工程：可验证奖励优先，模型奖励「少而精」

R1 主用规则奖励（数学 exact-match、代码编译器/单元测试），刻意避免神经网络奖励模型（易 reward hacking）；模型式 helpfulness/safety 奖励仅后期少量使用。

> 借鉴：agentrt 的 RLVR 只对「可验证任务结果」（退出码、测试通过、验收标准）开放强化通道；开放型任务用 rubric 自评兜底（与 Kimi Self-Critique Rubric、智谱可验证任务课程三方共识）。

### 3.4 后训练算力投入比例上调 + 可抢占容错 rollout 服务

V3.2 把后训练预算提升到预训练的 10% 以上 + 大规模 Agentic 任务合成（1800+ 环境、8.5 万复杂提示词驱动 RL）；V4 后训练包含**可抢占且容错的 rollout 服务**、Agentic AI 沙箱基础设施。

> 借鉴：think_d/执行链做成**可抢占 + checkpoint 恢复**的 rollout 服务：长任务中途被调度抢占后能从检查点续跑，任务大厅支持抢占式调度提升整体吞吐。

## 五、最核心可借鉴的 8 条工程思想

1. **软约束替代硬惩罚**：约束（负载均衡、限流）以可调偏置/预算形式放进调度机制，不污染主目标 → sched_d 软路由、双思考预算。
2. **把「等待」变成「重叠」**：算完再传/传完再算的地方用流水线/重叠藏进对方时间片 → GCCP 通信-思考重叠、daemon 间流水线。
3. **资源约束写进目标函数**：在受限成本下定义「每单位成本能解决的问题量」→ token/算力/时间预算成为一等调度维度。
4. **多阶段收敛的 RL 工程化**：能力靠 RL 涌现、可用性靠 SFT 塑形、经验靠拒绝采样沉淀、能力迁移靠蒸馏 → Agent 自我进化四阶段流水线 + 轨迹模板库（L4 记忆）。
5. **可验证奖励优先**：奖励越客观越优先，主观模型奖励少而精 → RLVR 只对可验证任务结果开放强化通道。
6. **先索引后精读的分级访问**：所有长内容访问采用「廉价粗筛 → top-k 精读」两段式 → 四层记忆两级召回与热冷分层。
7. **计算-存储分离 + 强一致 + 熟悉接口**：存储/记忆作为解耦资源池线性扩展 → 四层记忆系统架构范式。
8. **模块化开源 + 机制级消融 + 确定性可复现**：生产级小组件 + 公开数据 + 消融 + 确定性内核 → 17 个 daemon 独立可复用、机制内置 A/B 开关。
