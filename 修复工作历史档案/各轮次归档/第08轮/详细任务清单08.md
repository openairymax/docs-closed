## 一、Phase 4 剩余问题修复任务详情（清零冲刺）

### 🔴 R-01：platform.h NOMINMAX #ifndef保护

| 项 | 内容 |
|----|------|
| **文件** | `agentos/commons/platform/include/platform.h` L105 |
| **问题** | `#define NOMINMAX` 缺少 `#ifndef` 保护。当 MSVC 命令行已定义 NOMINMAX 时，产生 C4005 宏重定义警告 → `/WX` 级别转为编译错误 |
| **违反规范** | CROSS-05：Windows头文件保护 |
| **修复** | `#define NOMINMAX` → `#ifndef NOMINMAX\n#define NOMINMAX\n#endif` |
| **验证** | MSVC `/WX` 级别 `cmake --build` 零错误零警告 |
| **工时** | 5分钟 |
| **团队** | TeamB |
