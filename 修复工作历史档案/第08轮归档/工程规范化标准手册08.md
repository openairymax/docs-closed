## 1. 代码质量铁律（10禁止+8强制+5SDK）

### 1.1 禁止模式

| 编号 | 禁止 | 检测命令 |
|------|------|----------|
| BAN-01 | `return AGENTOS_SUCCESS`占位 | `grep -rn "return AGENTOS_SUCCESS" --include="*.c"` |
| BAN-02 | `(void)param`忽略 | `grep -rn "(void)" --include="*.c"` |
| BAN-03 | 空函数体`{}` | 代码审查 |
| BAN-04 | `TODO/FIXME`无Issue | `grep -rn "TODO\|FIXME" --include="*.c"` |
| BAN-05 | `simplified/placeholder/stub`注释 | `grep -rn "simplified\|placeholder\|stub" --include="*.c"` |
| BAN-06 | `return STRDUP(input)`回显 | 代码审查 |
| BAN-07 | `*out=(void*)1`假指针 | 代码审查 |
| BAN-08 | `while(cond){break;}`假循环 | 代码审查 |
| BAN-09 | `free("literal")` | `grep -rn 'free("' --include="*.c"` |
| BAN-10 | `*(ptr)=val`假原子 | 代码审查+TSan |
| BAN-11 | **桩头文件(`*_stub.h`)** | `find . -name "*_stub.h"` |
| BAN-12 | **降级模式返回假成功** | `grep -rn "degraded\|fallback.*SUCCESS" --include="*.c"` |
| BAN-13 | **DUMMY数据** | `grep -rn "DUMMY\|dummy" --include="*.c" --include="*.h"` |

### 1.2 强制模式

| 编号 | 强制 |
|------|------|
| REQ-01 | 每个公共API必须有单元测试 |
| REQ-02 | 每个修复必须通过L1编译+L2功能+L3回归 |
| REQ-03 | 内存分配检查返回值 |
| REQ-04 | 锁获取/释放在同一可见范围 |
| REQ-05 | 共享数据必须原子操作或锁 |
| REQ-06 | 禁止直接使用pthread.h — 必须使用`platform.h`抽象层 |
| REQ-07 | 错误码使用枚举非数字 |
| REQ-08 | 声明与定义一致 — `taskflow.h`枚举与`taskflow_core.c`宏定义一一对应 |

## 2. 跨平台编译规范（v10.5新增）

### 2.1 跨平台原则（CROSS-01~06）

| 编号 | 规范 | 违规示例 | 正确做法 |
|------|------|---------|---------|
| **CROSS-01** | 禁止直接使用POSIX线程API | `pthread_create()`, `pthread_mutex_lock()` | 全部替换为`platform.h`的`agentos_thread_create()`, `agentos_mutex_lock()` |
| **CROSS-02** | 禁止使用C99 VLA变长数组 | `int arr[n]` | 使用`AGENTOS_MALLOC(n*sizeof(int))` + `AGENTOS_FREE` |
| **CROSS-03** | 禁止直接使用POSIX时间函数 | `clock_gettime(CLOCK_MONOTONIC, &ts)` | 使用`agentos_time_ns()`, `agentos_time_ms()` |
| **CROSS-04** | 禁止使用GCC扩展语法 | 嵌套函数指针、语句表达式 | 使用ANSI C标准语法 |
| **CROSS-05** | Windows头文件保护 | `#define NOMINMAX`缺少`#ifndef` | 使用`#ifndef NOMINMAX / #define NOMINMAX / #endif`三行 |
| **CROSS-06** | MSVC `/WX` 级别零警告 | 未使用变量、隐式类型转换 | MSVC编译必须`/WX`标志零警告通过 |

### 2.2 跨平台编译验证流程

```
Step 1: cmake -B AgentOS-build          # 配置阶段（无错误）
Step 2: cmake --build AgentOS-build     # MSVC编译（0错误0警告）
Step 3: WSL cmake --build               # GCC编译（0错误0警告）
Step 4: CI双平台流水线                  # GitHub Actions Windows+Linux
```

### 2.3 允许的编译器特性（跨平台安全列表）

| 特性 | C标准 | 说明 |
|------|-------|------|
| `_Static_assert` | C11 | MSVC 2015+支持 |
| `_Generic` | C11 | MSVC 2022+支持 |
| `__func__` | C99 | 全平台支持 |
| `inline` | C99 | 全平台支持 |
| `stdint.h` | C99 | 全平台支持 |
| `inttypes.h` | C99 | 全平台支持 |

### 2.4 禁止的编译器特性（跨平台不安全列表）

| 特性 | 原因 | 替代方案 |
|------|------|---------|
| VLA变长数组 | MSVC不支持 | `AGENTOS_MALLOC`+`AGENTOS_FREE` |
| `pthread.h` | Windows无此头文件 | `platform.h`抽象层 |
| `clock_gettime` | Windows无此函数 | `agentos_time_ns()` |
| `fork()` | Windows不支持 | `agentos_process_start()` |
| GCC语句表达式 | MSVC不支持 | 普通复合语句 |
| `typeof` | MSVC不支持 | 显式类型名 |

## 5. PR提交规范

### 格式
```
[Team] P3-XX: 描述 (+ IMP-XX 若涉及融合)
例: [TeamA] P3-A01: 实现context_processor上下文处理器链 (IMP-06)
例: [TeamB] P3-B02: 替换pthread为platform.h跨平台抽象 (CROSS-01)
例: [TeamC] P3-C01: 创建TypeScript PluginSDK (IMP-10)
```

### 必须包含
```
□ 修复/实现代码 (源文件修改)
□ 测试代码 (测试文件新增)
□ 编译验证输出 (cmake --build / tsc / cargo build / go build / pytest)
□ 功能验证输出 (ctest / 自定义测试)
□ 无 BAN-01~BAN-13 违规
□ 跨平台验证 (CROSS-01~06 合规)
```
